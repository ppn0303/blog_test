# 커뮤 체질 검사

한국 온라인 커뮤니티·SNS·유튜브 이용 습관을 25개 문항으로 살펴보는 정적 웹 테스트입니다.

## 특징

- 5개 영역별 점수와 방사형 프로필
- 커뮤니티 친숙도와 판단·생활 침투도를 분리한 유형 판정
- 특정 영향 영역이 총점에 가려지지 않도록 별도 경고 표시
- 서버, 쿠키, 분석 도구 없이 브라우저 안에서만 채점
- 모바일·키보드 접근성 대응

## 로컬 실행

별도 빌드 과정이나 패키지 설치가 필요하지 않습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여십시오.

## 채점 주의

이 결과는 비표준화 자기보고형 테스트의 편집적 분류입니다. 심리·의학적 진단이나 정식 척도로 사용할 수 없습니다. 문항 구성과 구간값을 바꿀 때에는 실제 표본을 이용한 신뢰도·타당도 검증이 필요합니다.
